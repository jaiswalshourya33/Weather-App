# 🌦️ Weather App

A simple and responsive weather application that provides real-time weather information for any city. Users can check temperature, humidity, wind speed, and weather conditions instantly.

## 🚀 Live Demo

🔗 [View Live Demo](https://weather-app-yb6s.vercel.app/)

## ✨ Features

- Search weather by city name
- Real-time weather updates
- Temperature, humidity, and wind details
- Clean and responsive design
- Fast and easy to use

## 🛠️ Built With

- React.js
- JavaScript
- CSS
- Weather API

## 📦 Installation

```bash
git clone https://github.com/jaiswalshourya/weather-app.git
cd weather-app
npm install
npm run dev
